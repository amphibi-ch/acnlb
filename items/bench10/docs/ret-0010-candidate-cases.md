# 候选案例摘要（检索系统返回，合成示例）

**说明：合成示例，案号为虚构或公开案例改写，仅用于评测演示。**

**本案案情**：投资方 A 与目标公司 B 的控股股东 C 签订《增资协议之补充协议》，约定 B 公司
三年内未上市则由 C 按本金加年化 8% 收益回购 A 持有的股权；同时约定 B 公司对该回购
义务承担连带清偿责任。现 B 未按期上市，A 诉请 C 履行回购义务、B 承担连带责任。

【案例 1】苏州工业园区海富投资有限公司诉甘肃世恒有色资源再利用有限公司等增资纠纷再审案
（最高人民法院，(2012)民提字第 11 号）——最高人民法院认定：投资人与股东之间的对赌
（补偿）约定有效；投资人与目标公司之间的对赌约定使投资人可脱离经营业绩取得固定回报，
损害公司及债权人利益，该部分无效。

【案例 2】江苏华工创业投资有限公司与扬州锻压机床股份有限公司等请求公司收购股份纠纷再审案
（江苏省高级人民法院，(2019)苏民再 62 号）——法院认定：目标公司回购本公司股份的约定
不因主体为目标公司而当然无效；在履行回购前目标公司须完成法定减资程序，回购具备履行
可能性的，约定有效。

【案例 3】宋文军诉西安市大华餐饮有限公司股东资格确认纠纷案（最高人民法院指导案例 96 号）
——公司章程规定"人走股留"、由公司回购离职股东股权，法院认定该章程条款有效。

【案例 4】张某诉李某股权转让纠纷案（某中级人民法院，2018）——双方签订股权转让协议后，
受让方以转让方隐瞒目标公司债务为由诉请减少转让价款，法院依据欺诈规则部分支持。

【案例 5】王某诉某贸易公司民间借贷纠纷案（某基层人民法院，2020）——出借人诉请借款人
还本付息，借款人抗辩款项实为投资款，法院认定为借贷关系并支持还本付息。
