# 《技术服务合同》摘录（合成示例）

**说明：合成示例，非真实合同。委托人 = 甲方（委托方）。**

第三条 服务费：乙方完成全部服务后 90 日内，甲方支付服务费 50 万元。
第五条 知识产权：乙方在服务过程中形成的全部成果（包括基于甲方提供资料完成的改进）归甲方所有，甲方无须另行付费。
第七条 保密：甲方对在服务过程中知悉的乙方技术资料负有保密义务，保密期限为合同终止后 1 年。乙方对甲方商业秘密的保密义务同前款。
第八条 违约责任：任何一方违约，应向守约方支付违约金 2000 元。
第十条 争议解决：因本合同发生的争议，双方可协商解决；协商不成的，任何一方可向乙方住所地人民法院起诉。
