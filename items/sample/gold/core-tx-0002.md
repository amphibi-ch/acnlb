# core-tx-0002 参考答案 — 双向保密协议（NDA）要点

**说明：合成示例。**

1. **性质**：双向（mutual）保密协议，义务对双方对等。
2. **保密信息定义**：一方以书面、电子或口头方式向另一方披露、且标注为保密或依其性质合理应被识别为保密的信息，包括口头披露后以书面确认的信息。
3. **保密例外**：接收方接收前已合法持有；非因接收方违约而已进入公有领域；由无保密义务的第三方合法提供；接收方独立开发。
4. **使用限制**：保密信息仅可用于评估本次并购交易之目的，不得用于其他用途，不得向无关第三方披露（为交易目的必需的专业顾问除外，且受同等保密义务约束）。
5. **保密期限**：自披露之日起三至五年（可约定商业信息与个人信息不同期限）。
6. **救济**：违约时受损方可要求禁令、赔偿损失；可约定违约金作为救济方式（注意《民法典》第 585 条的调整规则）。
7. **返还/销毁**：交易终止或经披露方要求时，接收方应返还或销毁保密信息及其全部复制件，并出具书面确认。
