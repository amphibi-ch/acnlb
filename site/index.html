CN Legal Bench

Actions Sample items

A benchmark for Chinese-law tasks. Each item bundles a task, optional documents, a gold answer and a rubric of atomic propositions — plus a closed taxonomy for the CN-specific failures: citing repealed law, inventing a 司法解释, treating a 参考性案例 as binding.

面向中文法律任务的评测框架。每道题包含任务、可选附件、参考答案，以及由原子化得分点构成的 rubric，并配备一套封闭的负分分类体系，专门捕捉中文法律场景特有的失误：引用已废止法律、 编造司法解释、把参考性案例当作约束性案例。

Run it locally

本地运行

Bring your own OpenAI-compatible key. The Actions workflow calls the very same command.

自备 OpenAI 兼容密钥。Actions 调用的正是同一条命令。

pip install pyyaml
export MODEL_API_KEY=sk-...

python -m acnlb run --items items/sample \
  --model models.example.yaml --judge manual

Sample items under items/sample are synthetic. Real matters are added privately. MIT licensed.

items/sample 下的示例题均为合成数据，真实题目私下添加。MIT 许可。
