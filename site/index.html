acnlb alpha CN Legal Bench alpha 中文法律评测

Does the model produce lawyer-quality CN work product?

模型能否产出达到律师水准的中文法律工作成果？

acnlb scores the deliverable a Chinese-law task would require, not a multiple-choice label. Each item ships a task, optional documents, a gold answer, and a rubric of atomic Does the response state X? points plus a closed negative-point taxonomy for the CN-specific failure modes — citing repealed law, fabricating judicial interpretations, treating a 参考性案例 as binding.

acnlb 评测的是中文法律任务所要求的工作成果，而非选择题答案。每道题包含任务、 可选附件、参考答案，以及由原子化「回答是否陈述了 X？」得分点与一套封闭负分分类体系构成的 rubric， 专门捕捉中文法律场景特有的失误——引用已废止法律、编造司法解释、把参考性案例当作约束性案例。

Three tracks

三个评测轨道

Core (reasoning + drafting) · Workflows (结构化抽取, 合同审查) · Retrieval (法条 / 类案 / 条款)

Core（推理与起草）· Workflows （结构化抽取、合同审查）· Retrieval（法条／类案／条款检索）

Scoring

评分

Σ(affirmative points hit) − Σ(negative points), floored at 0. Per-item and per-track — never only a mean.

Σ(命中得分点) − Σ(负分)，下限为 0。逐题与逐轨道报告，绝不止给出平均分。

Judge

评阅

manual (worksheet / verdicts file) is the reference. The llm judge is marked UNVALIDATED until a labeled set gives Cohen's κ ≥ threshold.

manual（评分表／评阅文件）为基准路径。 llm 评阅标注为 未验证， 直至在有标注集上算出 Cohen's κ ≥ 阈值。

Run locally

本地运行

Bring your own OpenAI-compatible key. The CLI is the single source of truth — GitHub Actions shells out to the very same command.

自备 OpenAI 兼容的 API 密钥。命令行是唯一入口——GitHub Actions 调用的正是同一条命令。

git clone <this-repo> && cd acnlb
pip install pyyaml
export MODEL_API_KEY=sk-...           # never commit this

# 1. inspect the sample items
python -m acnlb validate --items items/sample

# 2. score a frozen fixture (no API key, deterministic, run twice → identical)
python -m acnlb score \
  --response items/sample/fixtures/core-tx-0001.good.txt \
  --verdicts items/sample/fixtures/core-tx-0001.good.verdicts.json \
  --rubric   items/sample/core-tx-0001.rubric.md

# 3. run the model over the sample set (exports grading worksheets first)
python -m acnlb run --items items/sample --model models.example.yaml --judge manual

# 4. re-run with your verdicts once graded
python -m acnlb run --items items/sample --model models.example.yaml \
  --judge manual --verdicts runs/latest/worksheets
